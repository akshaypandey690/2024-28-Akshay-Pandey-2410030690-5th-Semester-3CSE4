## 📌 About the Internship

The internship focused on building a strong foundational understanding of ethical hacking and cybersecurity — the mindset, methodology, and basic tools used by security professionals to identify and analyse vulnerabilities in computer systems and networks in a lawful and controlled manner. It followed a structured, week-wise curriculum combining conceptual learning with hands-on practice, quizzes, and assessments, culminating in a Final Assessment Test.

**Organization:** EduSkills Academy — runs the AICTE–EduSkills Virtual Internship Program under the patronage of the **AICTE National Internship Portal**.

---

## 🎯 Objectives

- Understand the fundamental concepts, terminology, and legal/ethical boundaries of ethical hacking
- Learn the phases of hacking — reconnaissance, scanning, gaining access, maintaining access, covering tracks — from a defensive perspective
- Understand common network and system vulnerabilities and how they are exploited
- Get familiar with basic penetration-testing and scanning tools used by security professionals
- Learn the basics of malware, social engineering, and web-application vulnerabilities
- Understand the importance of security policies, cryptography basics, and countermeasures
- Successfully clear the weekly assessments and the Final Assessment Test

| Week | Module | Description |
|---|---|---|
| 1 | Introduction to Ethical Hacking | Overview of information security, ethical hacking concepts, terminology, and the legal/ethical framework governing security testing |

## 🔬 Practical Project: Basic Vulnerability Assessment of a Test Web Application

As a hands-on application of the concepts learnt, a small vulnerability-assessment exercise was carried out on a **local, purpose-built test web application** (a deliberately vulnerable practice app used only for learning — not a live or third-party system).

**Steps followed:**
- Set up a local, isolated test environment with a deliberately vulnerable sample web application
- Performed basic reconnaissance to note the technologies, pages, and forms used
- Used a basic Nmap scan on the local test server to check open ports and running services
- Manually checked the login form for a weak/default password and observed the application's response
- Documented observations along with simple recommended fixes (strong passwords, closing unused ports, keeping software updated)

**Outcome:** Translated the theoretical modules into a small hands-on activity, providing first-hand understanding of how a basic vulnerability assessment is carried out and documented in practice.
